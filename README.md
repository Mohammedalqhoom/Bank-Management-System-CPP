# Bank Management System — C++

A console-based Bank Management System developed using C++ to apply core programming and software development concepts through a practical financial application.

## Overview

The system provides functionality for managing bank clients, financial transactions, system users, and user permissions.

It uses file-based data persistence and a modular structure based on reusable helper libraries.

## Features

- User authentication
- Client management
- Add, update, delete, and find clients
- Deposit and withdrawal operations
- Total balances
- User management
- Role-based permissions
- Input validation
- File-based data persistence
- Modular helper libraries

## Technologies

- C++
- Visual Studio
- File Handling
- Standard C++ Library

## Programming Concepts

- Structured Programming
- Functions
- Structs
- Enums
- Vectors
- File I/O
- Input Validation
- Modular Programming
- CRUD Operations
- Authentication
- Role-Based Access Control
